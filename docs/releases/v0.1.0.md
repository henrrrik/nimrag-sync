The first release: nimrag-sync does on Linux what Garmin's inReach Sync 1.4.47 does on Windows and macOS,
step for step, for the inReach devices inReach Sync serves. Tried on an inReach Mini (1st generation).

## What it does

- **Signs in** to the Garmin account the inReach is on (as on explore.garmin.com); the password is kept in the
  desktop's keyring.
- **Shows what a sync would change** before it writes anything: contacts, address book, preset messages, quick
  texts, settings, waypoints, routes, tracks and Garmin's device commands.
- **Syncs as inReach Sync does:** contacts, address book, preset messages, quick texts and settings from Garmin
  to the device; waypoints and routes both ways; tracks to Garmin; Garmin's device commands run; and it tells
  Garmin each step went through. It keeps a copy of the device's tables first
  (`~/.local/share/nimrag-sync/backups/`) and reads the device back after.
- **Switches the device** on, or to its USB drive mode (in which an inReach Mini takes its software updates).
- A **command line** for everything the window does (`nimrag-sync help`), with `--json`.
- English and Swedish; follows Omarchy's theme and language.

## Where it differs from inReach Sync

- It does not install software through the device's bootloader (the older DeLorme models): when Garmin offers
  an update, it stops and says so. An inReach Mini takes its updates as a USB drive.
- It sends no usage report and no copy of the device's event log to Garmin.
- It keeps a backup of the tables a sync changes.

As inReach Sync does, a sync writes Garmin's data over the device's: preset messages lose a MapShare
recipient that only Garmin's phone app adds, and Garmin's device commands set some settings back to Garmin's
values each time. The preview shows what changes.

## Install

Arch Linux and Omarchy, x86_64 and aarch64:

```sh
sudo pacman -U https://github.com/henrrrik/nimrag-sync/releases/download/v0.1.0/nimrag-sync-0.1.0-1-x86_64.pkg.tar.zst
```

`SHA256SUMS` lists the packages' checksums.
