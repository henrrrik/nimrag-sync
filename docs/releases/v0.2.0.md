Software updates for the inReach Mini.

## New

- **Software updates as a USB drive.** With the inReach Mini in its USB drive mode, nimrag-sync asks Garmin's
  update server what there is for it, downloads the update, checks its size and MD5, copies it onto the drive
  and ejects the drive; the inReach installs it when it restarts, as with Garmin Express. In the window this is
  the "Software updates" part of a device in USB drive mode, which checks by itself; on the command line
  `nimrag-sync update` (a trial run without `--apply`; `--reinstall` offers the version it has too). It asks
  Garmin's server as itself: no Garmin account, no key.
- **`nimrag-sync eject`** ejects an inReach's drive as the file manager does.
- When Garmin's inReach service offers new software during a sync, the message now says how to install it with
  nimrag-sync.

Tried on an inReach Mini: software 3.90 reinstalled this way, the device took the file within seconds of the
eject.

## Install

Arch Linux and Omarchy, x86_64 and aarch64:

```sh
sudo pacman -U https://github.com/henrrrik/nimrag-sync/releases/download/v0.2.0/nimrag-sync-0.2.0-1-x86_64.pkg.tar.zst
```

(`aarch64` in place of `x86_64` on ARM.) `SHA256SUMS` lists the packages' checksums.
